## 프롬프트 사용 가이드

### 기본 원칙
1. 모든 프롬프트는 건축물의 원형 구조를 유지하면서 예술적 재해석을 수행합니다
2. 각 스타일의 고유한 특징을 강조하여 명확한 차별화를 제공합니다
3. 고품질 이미지 생성을 위해 "masterpiece", "highly detailed" 등의 품질 지시어를 포함합니다
4. 부정적 프롬프트는 사용하지 않으며, 긍정적 지시사항만으로 원하는 결과를 유도합니다

### 프롬프트 구조
```
[기본 품질 지시어] + [스타일 정의] + [건축물 구조 유지] + [스타일별 특징 묘사] + [색상 및 질감] + [분위기 및 효과] + [세부 품질 강조]
```
